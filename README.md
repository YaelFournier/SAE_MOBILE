
# SAE Mobile - Application Mobile de Gestion

Projet développé dans le cadre de la SAE mobile.  
Cette application mobile a pour objectif de fournir une interface intuitive pour la recherche de restaurants dans une ville avec des utilisateurs.

## 📱 Technologies utilisées

- **Dart**
- **Flutter** 
- **Supabase**
- **GitHub** 

## 🚀 Fonctionnalités

- Consultation des restaurants
- Recherche des restaurants par noms
- Connection/inscription
- Ajouter des restaurants aux favoris
- Faire une recherche par type de cuisne
- Modifier le thème de l'application
- Notation des restaurants
- Gestion des notation des restaurants
